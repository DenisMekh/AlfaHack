# AlfaHack — персональная бизнес-аналитика

План прототипа для кейса Альфа-Банка «Новостная аналитика для принятия бизнес-решений».
Сервис помогает руководителю понять, как событие связано с его компанией, какие риски и возможности возникают и на каких источниках основан вывод.

**Статус:** подготовка проекта. Приложение, модели и развёртывание ещё не реализованы. Документы описывают предлагаемый MVP, а не готовые функции.

## Начать работу

1. Прочитать [ТЗ и ограничения](docs/requirements.md), [продукт](docs/product.md) и [архитектуру](docs/architecture.md).
2. Выбрать роль в [плане команды](docs/team.md), указать владельца и взять первую задачу.
3. Прочитать [правила Git](CONTRIBUTING.md), [контракты](docs/contracts.md), [правила агентов](AGENTS.md) и свой файл в `docs/agents/`.
4. Создать ветку от актуального `main`, работать в своей области, открыть PR.

```sh
git clone https://github.com/DenisMekh/AlfaHack.git
cd AlfaHack
git switch -c feat/<role>-<task>
```

## Предлагаемые компоненты

Python 3.12 + FastAPI, PostgreSQL с полнотекстовым поиском, React + TypeScript + Vite, отдельный worker, адаптер разрешённых LLM, Docker Compose. Версии зависимостей и lock-файлы добавляются при реализации компонентов. Для первого поиска достаточно SQL/лексического ранжирования: embedding-модель требует отдельного уточнения допустимости.

## План запуска и проверки

Целевой единый запуск — `docker compose up --build`; команда пока **не реализована**. R5 добавляет Compose, фиксированные зависимости и инструкции; R2–R4 реализуют сервисы. Ключи заполняются локально по `.env.example`, не коммитятся. Должны быть профили mock (синтетическая демонстрация без LLM), API и local. Mock явно помечается и не считается работающим AI.

Проверочный сценарий: выбрать компанию и роль → получить ранжированную ленту → раскрыть влияние события и первоисточники → сменить компанию и сравнить выдачу → загрузить ранее не показанную новость → увидеть анализ и трассу самопроверки. Тестовые компании синтетические, исходные данные организаторов не публикуются.
