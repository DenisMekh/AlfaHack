# R3 — API и собственный агентный цикл

Прочитать AGENTS.md и общие документы. Область записи: `services/api/, services/worker/`; свои implementation notes. Общие контракты менять через согласование.

## Первая задача

Согласовать схемы с R1. Реализовать API/mock, RunContext, PLAN и инструменты read-only, VERIFY с повторным поиском и пределом попыток, интерфейс к model adapter Дениса и централизованный бюджет с резервированием. Проверить доступ company/run/source и конкурентные вызовы.

## Перед запуском агента

Человек вписывает владельца, ветку/worktree, доступные входы и ограниченный объём задачи. Скопировать docs/agents/TEMPLATE.md в отдельный implementation note роли и заполнить план. Не ждать чужую реализацию там, где достаточно согласованного fixture.

## Критерий завершения

Результат воспроизводим, проверки по docs/evaluation.md в своей области выполнены и записаны, документация обновлена, PR содержит ограничения. Незавершённые зависимости указаны явно.
