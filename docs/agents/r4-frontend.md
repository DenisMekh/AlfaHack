# R4 — интерфейс

Прочитать AGENTS.md и общие документы. Область записи: `apps/web/`; свои implementation notes. Общие контракты менять через согласование.

## Первая задача

Сделать постоянный вход в демонстрационной оболочке банка, выбор компании и роли, ранжированную ленту, карточки и источники. Начать с общих синтетических fixtures. Показывать разделение фактов/банка/AI, missing/partial, ошибки и mock. Подключить API без дублирования бизнес-логики.

## Перед запуском агента

Человек вписывает владельца, ветку/worktree, доступные входы и ограниченный объём задачи. Скопировать docs/agents/TEMPLATE.md в отдельный implementation note роли и заполнить план. Не ждать чужую реализацию там, где достаточно согласованного fixture.

## Критерий завершения

Результат воспроизводим, проверки по docs/evaluation.md в своей области выполнены и записаны, документация обновлена, PR содержит ограничения. Незавершённые зависимости указаны явно.
