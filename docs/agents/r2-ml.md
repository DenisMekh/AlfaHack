## A1 — поиск с первоисточниками

На синтетических материалах реализовать нормализацию документа и chunks, точные дубли с сохранением всех URL, лексический поиск по новости/банковской аналитике, page/chunk locator и даты. Уточнить внутренний API с Романом Шваровым. Выдача возвращает evidence, не только текст.

Готовность: новая новость индексируется без правки кода, цитата совпадает с source fragment, отсутствие релевантной аналитики банка даёт пустой результат. Проверить дубли, устаревшие и конфликтующие документы. PDF-извлечение включать без неподтверждённого OCR-сервиса.

## A2 — персональный rank

Сопоставлять отрасль/продукты/связи/роль с событием, возвращать score и объяснимые составляющие. Компания не обязана быть названа в новости. Unknown не превращается в false exposure. Согласовать структуру с Денисом, одинаковая новость даёт разные ранги для разных клиентов/ролей.

Готовность: baseline по свежести, отраслевой baseline и персональный rank сравниваются на одном holdout; веса и ограничения записаны. Не использовать accuracy старой тональности как результат нового решения.

## A3 — набор оценки

Разметить ≥30 пар клиент–событие двумя участниками; отделить события/время train-tuning от holdout. Оценить P@5/nDCG@5, поддержку claims и конкретность влияния. Обязательно unseen news, пропуски, инъекция инструкций и конфликт банка/новостей. Цели из evaluation — не фактические результаты.
