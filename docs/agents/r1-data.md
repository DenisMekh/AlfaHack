# R1 — данные и продукт

Прочитать AGENTS.md и общие документы. Область записи: `services/data/`; свои implementation notes. Общие контракты менять через согласование.

## Первая задача

Проверить реальные CSV и права использования. Создать dictionary полей и report пропусков/единиц. Реализовать CompanyContext и связи с provenance; три полностью синтетических профиля. Не выводить неизвестные свойства из косвенных маркеров. Согласовать контракты с R3.

## Перед запуском агента

Человек вписывает владельца, ветку/worktree, доступные входы и ограниченный объём задачи. Скопировать docs/agents/TEMPLATE.md в отдельный implementation note роли и заполнить план. Не ждать чужую реализацию там, где достаточно согласованного fixture.

## Критерий завершения

Результат воспроизводим, проверки по docs/evaluation.md в своей области выполнены и записаны, документация обновлена, PR содержит ограничения. Незавершённые зависимости указаны явно.
