# R5 — Денис: LLM и интеграция

Прочитать AGENTS.md и общие документы. Область записи: `services/llm/, infra/, scripts/, .github/`; свои implementation notes. Общие контракты менять через согласование.

## Первая задача

Реализовать адаптер разрешённых моделей и промпты интерпретации совместно с R2/R3. Роман Аксенов помогает с Compose/CI после данных. Проверить железо и доступный API без публикации ключей. Зафиксировать версии/lockfiles, реализовать Compose и healthchecks, CI по реальным компонентам, seed/smoke. Измерить inference до выбора VPS. Подготовить runbook чистого запуска и notices. Настройки GitHub и аренду не считать выполненными без проверки.

## Перед запуском агента

Человек вписывает владельца, ветку/worktree, доступные входы и ограниченный объём задачи. Скопировать docs/agents/TEMPLATE.md в отдельный implementation note роли и заполнить план. Не ждать чужую реализацию там, где достаточно согласованного fixture.

## Критерий завершения

Результат воспроизводим, проверки по docs/evaluation.md в своей области выполнены и записаны, документация обновлена, PR содержит ограничения. Незавершённые зависимости указаны явно.
