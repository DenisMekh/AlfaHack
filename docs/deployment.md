# Модели и развёртывание

Известное железо: RTX 3060 Ti 8 GB VRAM, i7-12700K, 32 GB RAM, Windows 11. Рекомендуемая среда для воспроизводимости — WSL2/Linux + Docker, совместимость GPU проверить на месте. Перенесён исходный BrandRadar; целевое решение кейса пока не реализовано. Не арендовать VPS до измерений и подтверждения доступного бюджета.

Основной путь к первому MVP — командный API. Для крупных MoE-моделей общий объём весов существенно больше активных параметров; 8 GB VRAM не следует считать достаточными. CPU/GPU offload может потребовать почти всю RAM и дать неприемлемую задержку. Локальный эксперимент ограничить по времени; точную модель не выбирать до проверки разрешённых весов. Не подменять разрешённые модели меньшими Qwen/Gemma других версий.

1. R5 выясняет GPU/VRAM, RAM, ОС, диск домашнего ПК; R2 проверяет точные веса/лицензию одной разрешённой модели и разрешённость квантования. Active parameters MoE не равны объёму всех весов: 35B при 4 bit — около 17.5 GB только сырых весов, без KV/cache/runtime, это не обещание запуска на видеокарте 16 GB.
2. Начальный путь интеграции — выданный командный API через общий адаптер. Точные endpoint/model ID/тарифы/лимиты и timezone сброса уточнить. Не использовать персональные альтернативные LLM.
3. Local: inference-сервис отдельно от web/API; движок выбрать по совместимости точного checkpoint, замерить память, TTFT, полное время, tokens/s, качество русского JSON при контексте реального размера. Не считать наличие локального компьютера доказательством достаточности.
4. Для домашнего теста доступ через приватную сеть/VPN или SSH-туннель, токен сервиса; не открывать inference/БД в Интернет. Реальные данные не передавать без разрешения.
5. На защиту обычный VPS достаточен для web/API/БД при внешнем API. Для локальной большой LLM вероятно потребуется GPU-инстанс; подобрать по замерам и полной стоимости. Домашний ПК как единственная зависимость защиты ненадёжен.
6. R5 реализует Compose, healthchecks, migrations, импорт синтетических данных, pinned images/dependencies/lockfiles, backup и smoke-команду. Только reverse proxy доступен снаружи, HTTPS, секреты вне git, БД/inference в private network.

Runbook сдачи: fresh clone → env → build → migration/seed → health → две компании/роли → новая новость → проверка ссылок и повторного поиска → замер latency/cost → tag и полный commit SHA → инструкция жюри. При сбое API показывать ошибку и отдельно помеченный кэш с датой, не выдавать mock за живой анализ.

## Наследованные ограничения

См. docs/migration-report.md. Compose и Dockerfiles пока точная исходная база: ML требует веса MinIO, frontend собирается Bun, Go требует 1.26.1. Корневые LLM env пока проектные. Новый mock/API режим и отделение legacy weights — задачи R5. При переносе ничего не арендовано и не развёрнуто.
