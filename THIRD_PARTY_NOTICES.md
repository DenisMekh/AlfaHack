## Перенесённая кодовая база BrandRadar

Источник: https://github.com/DenisMekh/BrandRadar, commit 4254f75ee158098b61b7a5ea061254246c7be84e. MIT, copyright 2026 BrandRadar Team; оригинальный текст в LICENSE.brandradar. Все 379 исходных файлов сохранены по import-manifest, включая компонентные README и training notebooks. Изначально монорепозиторий объединяет backend/frontend/ml; авторство исходников и notices не удалять.

Фактические manifests baseline: backend/go.mod + go.sum; frontend/package.json + bun.lock + package-lock.json; ml/pyproject.toml + uv.lock; Docker images в Compose/Dockerfiles. Это фиксация существующего набора, не подтверждение успешной установки и совместимости всех зависимостей. Полный лицензионный реестр транзитивных пакетов остаётся релизной задачей. Существующий root LICENSE сохраняется и не заменяет LICENSE.brandradar.

Унаследованные ruBERT, SBERT, training/distillation Qwen3-235B упоминаются в исходной документации; веса в git отсутствуют. Эти модели не объявляются разрешёнными моделями кейса, качество из исходного README не является измерением нового решения. MinIO в baseline — зависимость старого ML; перенос не включает веса, содержимое S3/БД, .env или внешние данные.
